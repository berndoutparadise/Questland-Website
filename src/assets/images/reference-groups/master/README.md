# Questland core-team master reference

Canonical image: `questland-core-team-master.png`

Status: **FINAL — LOCKED**

This image is the binding identity and design reference for every future Questland
key art.

## Locked elements

- Facial identities and apparent ages
- Hairstyles
- Clothing designs and silhouettes
- Blue, orange, green and lime colour assignments
- Relative height and body proportions
- Character roles and signature equipment
- Lightly stylised premium 3D game-art rendering

Future images may change pose, expression within character, camera angle, lighting,
location and action. They must not redesign the characters.

When a generated image conflicts with this reference, correct the new image to match
this master. Never modify the master to match a later image.
